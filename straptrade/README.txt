STRAPTRADE WEBSITE

Complete static website with HTML, CSS, JavaScript, NFT artwork and the supplied whitepaper.

Pages: Home, The vision, How it works, Product, Roadmap, Whitepaper and Trade.
Trade intentionally shows Coming soon.

RUN LOCALLY
1. Extract this ZIP.
2. Open a terminal in the straptrade folder (the folder containing index.html).
3. With Python installed, run:
   python -m http.server 8000
   On Windows, you can also use: py -m http.server 8000
4. Open http://localhost:8000 in your browser.

Use a local web server instead of double-clicking index.html because links start at the website root.

HOSTING
Upload the contents of the straptrade folder to any static website host.
No build command or backend is required. The publish folder is the folder containing index.html.
Internet access loads the Google Fonts; system fonts work as a fallback.

EDITING
Edit each page's index.html. Shared styles are in style.css and interactions are in app.js.
The original whitepaper is documents/StrapTrade-Whitepaper.docx.
